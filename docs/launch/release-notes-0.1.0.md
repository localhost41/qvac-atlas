# QVAC Atlas 0.1.0 release notes

QVAC Atlas 0.1.0 is the first installable fixture-only developer preview for the
narrow, evidence-backed QVAC compatibility-registry workflow.

## Included

- An Apache-2.0 `qvac-atlas@0.1.0` package published from the exact deterministic
  artifact audited with `pnpm package:local`.
- Offline installation into a fresh non-workspace project with no runtime
  dependencies and no QVAC installation.
- Audit-before-publish, atomic no-clobber local artifact construction and an exact
  `ajv@8.18.0` validator pin with zero known production dependency advisories at
  candidate review time.
- Interactive synthetic fixture reports with disclosure, fingerprint
  acknowledgement, exact draft/final previews, publication-intent choice, local
  write confirmation, and no upload.
- A deterministic static evidence site with root and repository-subpath builds,
  keyboard/accessibility structure, narrow-screen layout, explicit evidence
  limitations, and strict fixture/genuine separation.
- A pinned GitHub Pages-compatible workflow that builds only by manual dispatch;
  deployment is a separate default-false, main-only, protected-environment job.
- Private-beta, independent-review, rollback, privacy/incident, and contributor
  walkthrough documentation.

## Deliberately unavailable

- Shipped real QVAC execution and model acquisition.
- Production profile admission, genuine report submission, and compatibility
  claims.
- Automatic upload, issue or pull-request creation, accounts, telemetry, repair,
  recommendations, scores, or a service backend.

## Evidence status

The checked-in site contains synthetic fixtures only. Fixtures are visibly labeled,
derive `unknown`, and cannot enter genuine claims. The earlier private physical run
remains nonconforming engineering evidence with `STOP / MANUAL REVIEW`; it does not
authorize activation or publication.

## Deliberately separate future gates

A fresh conforming ATLAS-013 run, production-profile admission, first
genuine-report ceremony and protected admission, and real-mode activation remain
separate future gates. The public fixture-only release does not satisfy or weaken
any of them.
